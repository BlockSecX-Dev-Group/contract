项目技术栈与功能概览

  技术栈

  | 层级   | 技术选型                                   |
  |--------|--------------------------------------------|
  | 前端   | Next.js + React + TypeScript + TailwindCSS |
  | 后端   | Python Flask + SQLAlchemy + APScheduler    |
  | 数据库 | MariaDB/MySQL                              |
  | 区块链 | Web3.py + BSC (BNB Chain)                  |
  | 容器化 | Docker (靶场环境隔离)                      |
  | AI能力 | Claude API (智能合约审计)                  |

  ---
  核心模块功能原理

  1. 钱包登录认证

  用户钱包签名时间戳 → 后端recover签名地址 → 签发JWT(12h有效期)
  - 无需传统账号密码，Web3原生认证
  - 签名验证使用 eth_account 库

  2. 靶场系统 (CTF Arena)

  用户创建靶场 → 扣除积分 → Docker启动容器 → 分配随机端口 → 写入Flag → 1小时超时自动销毁
  - 每个用户同时只能运行一个靶场
  - Flag格式: flag{24位随机字符}
  - 使用iptables动态管理端口访问

  3. 积分经济系统

  获取途径: 每日签到(连续奖励) + 答题挑战 + 视频学习
  消耗场景: 创建靶场 + AI合约审计(200积分/次)
  - 积分与代币分离设计 (UserPoints vs UserData)
  - 所有积分变动有审计日志

  4. 答题挑战

  开始答题(扣10积分) → 随机抽10题 → 20分钟限时 → 提交计分 → 超时自动0分提交
  - APScheduler定时任务处理过期会话
  - 题库按单元分类 (区块链基础/合约安全/DeFi等)

  5. 视频学习

  顺序解锁机制: 看完视频A → 解锁视频B
  防刷验证: 观看时长需达到80%-500%视频时长
  每日限制: 首个视频免费，后续每天解锁1个

  6. AI智能合约审计

  用户提交合约地址 → Etherscan获取源码 → Honeypot.is貔貅检测 → Claude分析漏洞 → 返回结构化报告
  - 支持链: BSC / Ethereum / Polygon / Base
  - 输出: 漏洞等级、风险描述、修复建议

  7. NFT铸造

  后端生成EIP-712签名参数 → 用户钱包签名 → 后端Meta-Transaction提交上链
  - 用户无需支付Gas费 (后端代付)
  - 使用EIP-712标准化签名

  ---
  架构亮点

  1. 去中心化身份: 钱包即账户，无传统注册流程
  2. 容器隔离: 每个靶场独立Docker环境，安全隔离
  3. 游戏化激励: 积分+排行榜+NFT徽章驱动用户学习
  4. AI增强: Claude提供专业级合约安全分析能力
